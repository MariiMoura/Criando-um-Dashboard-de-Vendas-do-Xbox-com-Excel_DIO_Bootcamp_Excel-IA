# 📊 Dashboard de Vendas no Excel

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO com o objetivo de transformar dados brutos de vendas em informações visuais claras e úteis por meio da criação de um dashboard interativo no Excel.

A proposta consiste em organizar, tratar e apresentar os dados de forma estratégica, permitindo acompanhar indicadores de desempenho e apoiar a tomada de decisões baseada em dados.

## 🎯 Objetivos do Projeto

- Criar um dashboard de vendas utilizando Microsoft Excel.
- Transformar dados em informações visuais de fácil interpretação.
- Facilitar o acompanhamento dos principais indicadores de vendas.
- Aplicar técnicas de análise e visualização de dados.
- Desenvolver habilidades em construção de relatórios gerenciais.

## 📈 Indicadores Monitorados

O dashboard apresenta informações como:

✅ Faturamento total;

✅ Quantidade de vendas realizadas;

✅ Vendas por período;

✅ Vendas por categoria;

✅ Produtos mais vendidos;

✅ Comparativos de desempenho;

✅ Indicadores visuais para análise rápida dos resultados.

## 🛠️ Recursos Utilizados

Durante o desenvolvimento foram aplicados diversos recursos do Excel:

- Tabelas Dinâmicas;
- Gráficos Dinâmicos;
- Segmentação de Dados (Slicers);
- Fórmulas e Funções;
- Formatação Condicional;
- Tratamento e organização de dados;
- Design de dashboards.

## 🚀 Como Utilizar

1. Faça o download do arquivo `Dashboard_Vendas.xlsx`.
2. Abra a planilha no Microsoft Excel.
3. Acesse a aba do dashboard.
4. Utilize os filtros e segmentações disponíveis.
5. Analise os indicadores e gráficos apresentados.
6. Explore diferentes perspectivas para acompanhar o desempenho das vendas.

## 📊 Benefícios da Solução

- Visualização rápida dos resultados de vendas;
- Melhor acompanhamento dos indicadores de negócio;
- Facilidade na identificação de tendências;
- Apoio à tomada de decisões baseada em dados;
- Maior praticidade na análise de informações.
